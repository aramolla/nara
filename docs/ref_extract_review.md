# 항 단위 조문 참조 추출 테스트 검토

`prep/ref_extract_test.py`로 항 1개씩 Gemma에 넣어 참조 조문을 추출한 결과와, 그 결과에서 발견한 문제·해결을 기록한다.

- 모델: google/gemma-4-26B-A4B-it (int8_per_channel_weight_only, max_model_len 16384)
- 출력 스키마: `prep/ref_schema.json` (vLLM 구조화 출력으로 강제, `follow`는 임시로 true 고정)
- 입력: 국가계약법 시행령 제12조 ②~⑥ (항마다 1회 호출, 5건 배치)


## 1차 실행 결과

5건 모두 `finish=stop`으로 스키마에 맞는 JSON이 나왔다. 다른 법령을 가리키는 참조(③의 8건 등)와 "법"·"같은 법" 해석은 정확했다.

| 항 | 모델 출력 | 정답 |
|---|---|---|
| ② | `제1항` [2] × 2 (중복) | 제12조 [1] |
| ③ | 제27조의5 [1] (모법) 외 타법 7건 | 동일 ✅ |
| ④ | 형의 실효법 제2조 [5], 제12조 [3] | 제2조 [], 제12조 [3] |
| ⑤ | `제4항` [], `제3항` [] | 제12조 [4], 제12조 [3] |
| ⑥ | `제3조` [], 제76조 [5,6,9,10] | 제12조 [3], 제76조 [5,6,9,10] |


## 문제와 해결

세 문제 모두 프롬프트에 처리 규칙이 없어서 모델이 추측한 것이 원인이다. `SYSTEM_PROMPT` 규칙 부분에 아래 규칙을 추가했다.

### 문제 1. 조 번호 없이 "제N항"만 쓴 참조

- 문제: "제3항"은 현재 조(제12조)의 제3항인데, `article`에 "제3항"이나 "제3조"를 넣었다 (②⑤⑥).
- 해결:
  ```
  조 번호 없이 "제N항"만 쓰면 현재 조의 제N항을 가리킨다. article에는 현재 조 번호를 적는다.
  - 현재 조가 제12조일 때 "제3항" → article: "제12조", paragraphs: [3]
  ```

### 문제 2. 호 번호가 항 자리에 들어감

- 문제: 스키마에 호 필드가 없어서, "제2조제5호"의 5와 "제1항제2호"의 2를 `paragraphs`에 넣었다 (②④).
- 해결: 호는 항에 포함되므로 항까지만 적는다. 항 없이 호만 지정된 경우는 조 번호만 적고 `paragraphs`는 비운다.
  ```
  호는 항에 포함되므로 호 번호는 버리고 항까지만 적는다. 호 번호를 paragraphs에 넣지 않는다.
  - "제1항제2호" → paragraphs: [1]
  - "제2조제5호"(항 없이 호만 지정) → paragraphs: []
  ```

### 문제 3. 같은 참조 중복

- 문제: ②에서 "제1항제2호"가 원문에 두 번 나오자 ref도 2개 만들었다.
- 해결: 법령·조·항이 모두 같은 참조는 한 번만 만든다. 같은 조의 서로 다른 항은 `context`가 달라 별도 ref로 둔다.
  ```
  같은 참조 대상(법령·조·항이 모두 같음)이 여러 번 나와도 ref는 한 번만 만든다.
  ```


## 2차 실행 결과

문제 1~3 규칙 추가 후 재실행. 5건 모두 `finish=stop`.

| 항 | 모델 출력 | 정답 | 판정 |
|---|---|---|---|
| ② | `제1항` [2] × 2 (중복), 중소기업협동조합법 `""` [] | 제12조 [1] | ❌ 문제 1·2·3 그대로 + 조 번호 없는 법령명 참조 새로 추출 |
| ③ | 1차와 동일 | 동일 | ✅ (단, `text`에서 각 호 본문이 빠짐) |
| ④ | 형의 실효법 제2조 [], 제12조 [3] | 동일 | ✅ 문제 2 해결 |
| ⑤ | 제12조 [4], 제12조 [] | 제12조 [4], 제12조 [3] | △ 조 번호는 해결, "제3항 각 호"의 항 번호 누락 |
| ⑥ | 제12조 [3], 제76조 [5,6,9,10] | 동일 | ✅ 문제 1 해결 |

남은 문제:
- ②: "제1항제2호"(같은 조 + 호)에서 규칙이 전혀 적용되지 않음. 중복도 그대로.
- ②: 조 번호 없이 법령명만 나온 참조(「중소기업협동조합법」에 따른)를 `article: ""`로 추출.
- ⑤: "제3항 각 호"에서 항 번호를 버림.


## 방식 변경: LLM(표현·법령) + 코드(조·항 번호)

2차에서도 조·항 정리가 불안정해서 역할을 나눴다.

| 단계 | 담당 | 출력 |
|---|---|---|
| 참조 표현 찾기 | LLM | `expression` (원문 그대로, 조 번호가 있는 것만) |
| 법령 판별 | LLM | `law` |
| 조·항 번호 정리 | `prep/ref_parse.py` | `article`, `paragraphs` |
| 현재 항 정보, 중복 제거 | 코드 | `text`, `article`, `article_title`, `law`, `paragraph` |

- LLM 스키마: `prep/ref_llm_schema.json` (`refs[]`: expression, law, follow, context)
- 최종 스키마: `prep/ref_schema.json` (`refs[]` 맨 앞에 `expression` 추가, 조립 후 jsonschema로 검증)
- 번호 없이 법령명만 언급한 것(「중소기업협동조합법」에 따른)은 추출하지 않도록 프롬프트에 명시

### 파서 전수 검증

`python prep/ref_parse.py`: `model/law_chunks.json`의 번호 참조 표현 9,351건 중 실패 8건.

- 7건: `조의N`이 섞인 조 범위 (예: "제10조의13부터 제10조의17까지"). 조 목록이 있어야 펼칠 수 있음.
- 1건: "제4의2항". 정수 항 번호로 표현할 수 없음.
